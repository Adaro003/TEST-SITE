# Transform Pilates - Professional Studio Website

A modern, responsive website for Pilates instructors to attract clients and manage bookings.

## Features

- 🎯 Professional landing page with hero section
- 👤 About instructor section
- 🏋️ Services showcase (6 different offerings)
- 💰 Flexible pricing plans
- 📅 Online booking form
- 📞 Contact information
- 📱 Fully responsive design
- ⚡ Fast loading (single HTML file)

## Services

1. Mat Pilates
2. Reformer Pilates
3. Private Sessions
4. Group Classes
5. Rehabilitation
6. Corporate Wellness

## Pricing

- Single Session: $60
- 5-Session Package: $275 ($55/session)
- 10-Session Package: $500 ($50/session)
- Group Classes: $20/class

## Customization

Edit `index.html` to customize:
- Business name (change "Transform Pilates")
- Your phone number
- Your email
- Location/address
- Hours of operation
- Pricing and services
- Colors (look for `--primary`, `--secondary` in CSS)

## How to Use

1. The website is ready to deploy as-is
2. Open `index.html` in any browser
3. For production, upload to any web hosting service
4. Enable GitHub Pages in repository settings for free hosting

## Features

### Booking System
- Clients can book sessions with date/time selection
- Form validation
- Bookings saved to browser storage
- View bookings in browser console: `JSON.parse(localStorage.getItem('pilatesBookings'))`

### Admin Functions
- View all bookings: `JSON.parse(localStorage.getItem('pilatesBookings'))`
- Export bookings as CSV (coming soon)
